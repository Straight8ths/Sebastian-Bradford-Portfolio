# Financial Sandbox

A collection of various studies and experiments using financial data. My workhorse libraries for this are **yfinance**, **pandas**, and **matplotlib**.

**Note:** These exhibits are for demonstrating my own learning and experimentation. They are not financial advice, and should not be taken as such.

## Contents

- **Initial Tooling**
    - How I use the yfinance library to build my tools for later projects.

- **Intraday Movement vs. Return**
    - A study of high-low behavior and returns over time, visualized in 2D and 3D.
